# Ascend Face Scan

A phone web app that rates a face from 0 to 10 from a selfie, using facial-proportion research (symmetry, facial thirds, eye spacing, canthal tilt, fWHR, jaw width, lips, brows), plus skin, brow and lash analysis. Each measurement comes with fixes, worst first.

Everything runs on the device with Google's MediaPipe Face Landmarker. No photo leaves the phone.

## Install on iPhone
1. Open the GitHub Pages link in **Safari**.
2. Tap **Share**, then **Add to Home Screen**.
3. Open it from the home screen icon. It works offline after the first load.
